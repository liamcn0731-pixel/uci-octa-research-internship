# 实习工作总结

## 研究任务

在 UCI 暑期实习期间，围绕内窥 OCT/OCTA 对组织结构与微血管信号的分析开展工作。研究项目关注 GSM 背景下的影像特征，重点使用 VET（阴道上皮厚度）和 BVD（血管密度），探索其与 VHI、VSQ 等评分的关系。

工作报告列出 Zhongping Chen 为 faculty mentor，Zheng Li 为学生。完整采集系统、患者招募与临床评分属于实验室研究背景，现有材料支持个人贡献主要集中于处理算法、软件界面及数据分析。

## 图像处理改进

理解既有 B-scan/A-line 和重复采集流程，在原有处理代码上修改边界提取方式。当前实现将灰度图转换到 uint8，使用 Otsu 给出阈值，再分别进行较高与较低阈值的 Canny 边缘提取。低阈值图中的连通域若与高阈值边缘相交则保留。

代码逐列取最上方边缘点，并在没有边缘的列使用中间行作为回退值。随后按边界移动每一列，完成组织展平。重复帧差分与灰度加权产生运动相关信号图，再通过 ImageJ 进行重切片和分组投影。

补充说明记录修复 12 组边界识别错误，以及处理时间约 200 s 降为 72 s。这一结果没有附完整运行硬件、重复计时与统计误差，应作为实习期间的观察记录。

## 软件工具

开发 MATLAB GUI，将目录选择、图像预览、批处理、进度与取消操作接入图像处理流程。ImageJ 宏整合 Reslice 与每 10 张图像分组平均投影，减少重复菜单操作。

OCTAVA 用于血管分析的调研和整合。说明文件明确其密度测量准确性尚未确认，因此不将其写为本人原创软件，也不声称完成测量准确性验证。

## 建模与界面

围绕 VET、BVD 与健康评分进行相关性和回归分析，并尝试非线性或集成学习方法。当前保留的 MATLAB 脚本使用 LSBoost，以 VET、BVD、VET² 为特征拟合 VHI。

VSQ 当前源码按评分 `<=4` 与 `>4` 分成两个标签，使用 VET、BVD、AGE 为输入，采用多项式核 SVC 和五折分层交叉验证。Tkinter 界面加载分类器并输出类别。

报告描述过包含 VHI 与 VSQ 的综合界面，但本目录中的 Python GUI 实际只调用 VSQ 分类器。整理时按现有实现描述，避免把报告目标写为已交付功能。

## 面向项目介绍的简洁表述

在 UCI 暑期科研实习中参与 OCT/OCTA 图像分析，改进基于 Canny 与连通域筛选的组织边界检测和展平流程，开发 MATLAB 批处理 GUI 与 ImageJ 宏，并基于影像特征探索 VHI 回归、VSQ 分类及预测界面。补充报告记录特定处理任务耗时由约 200 s 降至 72 s，相关结果尚需独立复测。
